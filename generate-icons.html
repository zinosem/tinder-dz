📱 Comment installer sur iPhone

  1. Héberger l'app - Tu dois mettre ton app sur un serveur HTTPS (gratuit avec GitHub Pages, Netlify, ou Vercel)
  2. Sur ton iPhone, ouvre Safari et va sur l'URL de ton app
  3. Appuie sur le bouton Partager (carré avec flèche vers le haut)
  4. Fais défiler et appuie sur "Sur l'écran d'accueil"
  5. Donne un nom à l'app et appuie sur Ajouter
  6. 🎉 L'app apparaît sur ton écran d'accueil comme une vraie app!

🚀 Hébergement gratuit avec GitHub Pages

  1. Crée un compte sur github.com
  2. Crée un nouveau repository (ex: "lovedz")
  3. Upload tous tes fichiers
  4. Va dans Settings → Pages → Sélectionne "main" branch
  5. Ton app sera accessible sur https://tonpseudo.github.io/lovedz
